OWNER SETTINGS

Connect Cloudflare

Set up the connection for background episode creation. Use your usual browser—no Cloud Browser login needed.

Create a restricted API token

  1. Open Cloudflare API Tokens and choose Create Token → Create Custom Token.
  2. Name it Still Curious setup. Add account permissions Workers Scripts: Edit and Queues: Edit (Cloudflare may label these “Write”).
  3. Under Account Resources, select Include → Specific account and your account. Set an expiry date, such as seven days from today. Create the token.
  4. Copy your Account ID from the Cloudflare account dashboard. Paste both values below.

Use an API token, not your password or Global API Key. This connection needs no domain purchase or paid-plan upgrade.
